This function registers a callback function to handle out-of-bounds faults when they occur.

When the host detects an out-of-bound fault, the host may redirect the control flow to this callback.

The main purpose of the callback function is to:

1. Allow the pack to inspect the faulting operation.
2. Allow the pack to further redirect the control flow.

:::warning
This function is intended to be implemented in programming languages that does not support native exception handling or wherever the implementers deem it necessary to provide a more flexible way to handle out-of-bounds faults.

See more info at [`Best Practices`](/best-practices#faults).
:::

```obgx
onOOBFault(
    cb: (
        // !link[/"function"/] ../basic-handles@1/hndl_function
        origin: hndl("function"),
        // !link[/"array"/] ../basic-handles@1/hndl_array
        array: hndl("array"),
        length: u64,
        index: u64
    // !link[/OOBFaultFeedback/] OOBFaultFeedback
    ) => OOBFaultFeedback
): bool;
```
