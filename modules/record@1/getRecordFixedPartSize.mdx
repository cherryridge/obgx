This function returns the fixed part size of a record type, in bytes.

:::note
This function's return value is not standardized by OBGX, since OBGX does not define a standard representation for almost every fundamental type. Different implementations may also have different sizes for the "reference to a variable-size buffer" type.
:::

```obgx
// !link[/"record"/] hndl_record
getRecordFixedPartSize(record: hndl("record")): u64;
```
