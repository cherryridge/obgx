This enum describes the type of a field in a record.

```obgx
enum FieldType {
    I8, I16, I32, I64,
    U8, U16, U32, U64,
    F32, F64,
    Bool,
    String,
    // !link[/FieldTypeArray/] FieldTypeArray
    // !link[/\bFieldType\b/] FieldType
    Array(FieldTypeArray), Vector(FieldType),
    // !link[/"record"/] hndl_record
    Record(hndl("record"))
}
```
